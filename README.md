# Task 3: Linear Regression

## Objective

To implement and understand Simple and Multiple Linear Regression using a housing dataset.

## 🛠 Tools Used

* Python
* Pandas
* NumPy
* Matplotlib
* Scikit-learn
* Google Colab

## Dataset

* Housing dataset
* Target: `price`
* Feature: `area` (for simple regression)

## Steps Performed

1. Loaded dataset using Pandas
2. Converted categorical values (yes/no → 1/0)
3. Applied one-hot encoding
4. Split data into training and testing sets
5. Trained Linear Regression model
6. Made predictions
7. Evaluated model using MAE, MSE, and R²

## Results

* MAE: 1474748.1337969352
* MSE: 3675286604768.185
* R² Score: 0.27287851871974644

## Visualizations

* Area vs Price regression graph
* Actual vs Predicted graph

## Conclusion

The model shows a positive relationship between area and price. Multiple regression improves prediction accuracy.
